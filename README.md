# Khel-Sathi-New

The Khel Sathi Portal is a robust, multi-faceted sports management web application developed using the Laravel 8.x framework (PHP 7.3/8.0).

It serves as the central nervous system for the state's sports department, digitizing the interactions between athletes, coaches, administrative officials, and sports facilities.

## Technology Stack

- Laravel 8.x
- PHP 7.3 / 8.0
- MySQL

## About the Project

The application supports sports management operations and helps digitize interactions between athletes, coaches, administrative officials, and sports facilities.
